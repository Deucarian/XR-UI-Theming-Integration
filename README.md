# Deucarian XR UI Theming Integration

Optional integration package for projects that use both `com.deucarian.xr-ui` and `com.deucarian.theming`.

Add `XrUiThemePaletteIntegration` near a `DeucarianThemeProvider` to map theme role colors into the XR UI runtime palette. The XR UI core package remains fully functional without this package.
